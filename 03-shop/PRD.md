# 一枚手作 HandmadeOne — 产品需求文档（PRD）

## 一、项目定位

独立手作器物小店：粗陶咖啡杯、亚麻桌布、黄铜书签、手工蜡烛……商品不多，但每一件都是手作的。

视觉基调：陶土赭石色 + 米沙白，大块留白，商品卡突出质感。

## 二、核心功能

### 商品
- 商品列表：分类筛选、关键词搜索、排序（综合 / 价格升降 / 销量 / 最新）、分页
- 商品详情：图文介绍、价格、库存、选择数量、加入购物车

### 购物车
- 加入购物车：同商品数量累加，超过库存提示
- 数量增减、删除、实时小计
- 勾选要结算的商品

### 地址
- 增删改查；设默认地址；删除默认地址后自动把第一个设为默认

### 订单
- 提交订单：选地址、选优惠券（满减），事务内扣库存、保存下单时价格快照、生成订单号、清空对应购物车项
- 订单列表：按状态筛选（全部 / 待支付 / 已支付 / 已取消…）
- 订单详情：商品快照、地址、金额明细
- 取消订单：恢复库存、释放优惠券
- 模拟支付：把「待支付」改为「已支付」

### 优惠券（扩展）
- 我的优惠券：满 99 减 10 / 满 199 减 25 / 满 299 减 40
- 下单时自动校验门槛并抵扣

## 三、前端页面

| 路由 | 页面 | 权限 |
| --- | --- | --- |
| `/` | 商品列表 | 公开 |
| `/product/:id` | 商品详情 | 公开 |
| `/cart` | 购物车 | 需登录 |
| `/checkout` | 结算（地址 + 券 + 金额） | 需登录 |
| `/orders` `/order/:id` | 订单列表 / 详情 | 需登录 |
| `/addresses` | 地址管理 | 需登录 |
| `/login` `/register` | 登录 / 注册 | 公开 |

## 五、技术方案

- 前端：React 18 + TS + Vite + Tailwind + react-router-dom + axios
- 后端：Node.js + Express 4（config / middleware / controllers / routes）
- 数据库：MySQL 8（mysql2），本机演示可切换 SQLite
- 下单 / 取消 / 库存 / 券全部走数据库事务，保证一致性
- 认证：JWT + bcrypt；金额一律在服务端计算，前端传的金额不可信
