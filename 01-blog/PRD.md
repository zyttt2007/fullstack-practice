# 青苔笔记 MossNote — 产品需求文档（PRD）

## 一、项目定位

一个关于「旧书 · 城市漫步 · 手冲咖啡」的私人写作博客。访客可以浏览、搜索文章；注册用户可以写文章、存草稿、评论、点赞。

视觉基调：纸感米白底 + 墨绿（苔色）主色 + 衬线标题，卡片带细描边和柔和阴影，整体安静、克制。

## 二、核心功能

### 用户功能

- 注册：用户名（3-20 字符）、邮箱（格式校验）、密码（≥6 位）
- 登录：校验通过后返回 JWT token（有效期 7 天）
- 个人中心：查看 / 编辑头像、简介；管理「已发布」与「草稿箱」

### 文章功能

- 发布文章：标题、Markdown 正文、分类、标签、封面图、摘要
- 保存草稿：草稿不出现在首页，可在个人中心继续编辑后发布
- 编辑 / 删除文章：仅作者本人可操作
- 查看文章：Markdown 渲染，浏览数 +1，展示作者、发布时间、阅读时长
- 文章列表：分页（每页 6 条）、分类筛选、标签筛选、关键词搜索（标题 + 正文）
- 归档页（扩展）：按「年 - 月」聚合文章

### 互动功能（扩展）

- 评论：登录用户可评论，作者与评论者可删除
- 点赞：每人对每篇文章只能点赞一次，可取消，实时更新点赞数

## 三、前端页面

| 路由 | 页面 | 权限 |
| --- | --- | --- |
| `/` | 首页：文章列表 + 分类条 + 搜索 + 分页 | 公开 |
| `/post/:id` | 文章详情：Markdown 正文 + 点赞 + 评论 | 公开 |
| `/write` `/write/:id` | 写文章 / 编辑：左编辑右实时预览 | 需登录 |
| `/profile` | 个人中心：资料编辑 + 我的文章 + 草稿箱 | 需登录 |
| `/archive` | 归档：按月分组 | 公开 |
| `/login` `/register` | 登录 / 注册 | 公开 |

## 四、接口清单

### 认证 `/api/auth`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/register` | 注册，返回 token |
| POST | `/login` | 登录，返回 token |
| GET | `/me` | 当前登录用户 |
| PUT | `/profile` | 更新头像 / 简介 |

### 文章 `/api/posts`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 列表，支持 `page` `pageSize` `category` `tag` `keyword` `status` `authorId` |
| GET | `/:id` | 详情，浏览数 +1 |
| POST | `/` | 创建（`status` 可为 draft / published） |
| PUT | `/:id` | 更新（仅作者） |
| DELETE | `/:id` | 删除（仅作者） |
| GET | `/archive` | 按月归档 |
| POST | `/:id/like` | 点赞 / 取消点赞，返回 `liked` 与 `likesCount` |

### 评论 `/api/comments`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/?postId=` | 某篇文章的评论 |
| POST | `/?postId=` | 发表评论 |
| DELETE | `/:id` | 删除评论（作者或评论者） |

### 分类 `/api/categories`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 分类列表（含每类文章数） |

## 五、技术方案

- 前端：React 18 + TypeScript + Vite + Tailwind CSS + react-router-dom + axios + react-markdown
- 后端：Node.js + Express 4，分层为 `config / middleware / controllers / routes`
- 数据库：MySQL 8（驱动 mysql2），本机演示可切换内置 SQLite
- 认证：JWT（jsonwebtoken）+ bcrypt 密码加密
- 配置：`.env` 管理端口、数据库连接、JWT 密钥，不硬编码

## 六、非功能要求

- 统一错误处理中间件，返回 `{ error: { message } }` 结构
- 所有写接口做参数校验（长度、格式、必填）
- 密码永不返回前端（模型层统一剔除 `password` 字段）
