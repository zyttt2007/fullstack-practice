# 灶台问答 HearthAsk — 产品需求文档（PRD）

## 一、项目定位

面向新手下厨与家庭厨房的互助问答社区：提问要花积分，回答赚积分，好答案被点赞、被采纳能拿更多分。

视觉基调：灶火暖橙 + 奶油白，圆角卡片，亲切、有烟火气。

## 二、核心功能

### 用户功能
- 注册 / 登录（JWT），新用户送 100 积分
- 我的主页：积分、我的提问、我的回答

### 问题功能
- 提问：标题 + Markdown 详情 + 标签，发布扣 5 积分
- 问题列表：排序（最新 / 热门 / 未解决）、按标签筛选、关键词搜索、分页
- 问题详情：浏览数 +1、问题点赞、回答列表

### 回答功能
- 写回答：回答得 10 积分
- 回答点赞：每人一次
- 采纳答案：仅提问者可操作，每题只能采纳一个，采纳后问题标记「已解决」，回答者 +30

### 积分与激励
- 点赞规则：问题被赞 +5、回答被赞 +10；取消点赞反向扣回
- 积分排行榜（扩展）
- 热门标签（扩展）

## 三、前端页面

| 路由 | 页面 | 权限 |
| --- | --- | --- |
| `/` | 问题列表：排序 tab + 标签筛选 + 搜索 + 分页 | 公开 |
| `/ask` | 提问 | 需登录 |
| `/question/:id` | 问题详情 + 回答 + 点赞 + 采纳 | 公开 |
| `/leaderboard` | 积分排行榜 | 公开 |
| `/mine` | 我的：积分、我的提问、我的回答 | 需登录 |
| `/login` `/register` | 登录 / 注册 | 公开 |

## 四、接口清单

### 认证 `/api/auth`
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/register` | 注册，送 100 分 |
| POST | `/login` | 登录 |
| GET | `/me` | 当前用户（含积分） |
| PUT | `/profile` | 更新头像 / 简介 |

### 问题 `/api/questions`
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | `sort=latest\|hot\|unsolved`、`tag`、`keyword`、`page` |
| GET | `/:id` | 详情 + 回答列表，浏览数 +1 |
| POST | `/` | 提问，扣 5 分 |
| POST | `/:id/answers` | 写回答，加 10 分 |

### 互动
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/votes/toggle` | `{ targetType, targetId }` 点赞 / 取消，返回 `voted`、`votes` |
| POST | `/answers/:id/accept` | 采纳答案（仅提问者），回答者 +30 |

### 其他
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/tags` | 热门标签 |
| GET | `/leaderboard` | 积分前 10 |

## 五、技术方案

- 前端：React 18 + TS + Vite + Tailwind + react-router-dom + axios + react-markdown
- 后端：Node.js + Express 4（config / middleware / controllers / routes）
- 数据库：MySQL 8（mysql2），本机演示可切换 SQLite
- 数据一致性：点赞、采纳、提问 / 回答的积分变化全部走事务
- 认证：JWT + bcrypt
